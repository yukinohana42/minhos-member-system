# リンク漏えい・誤公開 Runbook

## 判定

- **外部URL漏えい、個人情報、権利問題**: P1。YouTube/Dropboxを先に停止する。
- **Ghostページだけの誤公開で外部URL取得なし**: Ghost記事を先に下書きへ戻してよい。

## 停止順

1. YouTube動画を非公開へ変更し、Dropbox共有リンクを無効化する。
2. Ghost本文から旧URLを除去し、必要なら記事を下書きへ戻す。
3. 新URLを発行する場合は `60_ContentRegistry` とGhost本文を同じ変更で更新し、旧URL無効化を確認する。
4. 影響範囲、取得可能期間、発見経路、通知判断、権利者連絡、再発防止を `80_OpsLog` へ記録する。

## 復旧・連絡

外部サービスの公開状態とGhostの非有料HTML、OGP、メール、検索面を確認します。影響する個人情報・権利がある場合は責任者・法務の通知判断を待ち、推測で個人へ連絡しません。MVPでは取得後URLの回収を保証できないため、必要に応じて動画／PDFの差し替えまたはStage C移行を検討します。
